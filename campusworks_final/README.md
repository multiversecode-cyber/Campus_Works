# CampusWorks - Complete Frontend

Complete React + Vite frontend for the CampusWorks college project.

## Included frontend phases

1. Landing page and public navigation
2. Authentication UI and role selection
3. Student dashboard, profile and applications
4. Explore, search, filters and opportunity details
5. Faculty and Club dashboards
6. Post opportunity and applicant management
7. Application lifecycle, notifications, reviews and admin UI
8. Responsive design and final frontend polish

## Run

```bash
npm install
npm run dev
```

Open:

http://localhost:5173/

## Important

This frontend currently uses local dummy data and local React state.
No Flask API or SQLite connection is required yet.

The UI is intentionally kept simple enough to explain in a college viva.
